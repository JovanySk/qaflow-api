How it runs in CI

Workflow .github/workflows/ci.yml, on every push to main and every pull request.

  1. Checkout and JDK 17Temurin 17 on ubuntu-latest with the Maven dependency cache.
  2. Unit tests./mvnw -B clean verify runs Surefire first for *Test classes.
  3. Integration testsFailsafe runs *IT classes; Testcontainers starts MySQL 8 on the runner's Docker.
  4. ReportsRaw XML and this HTML page are uploaded as build artifacts, even when tests fail.

Regenerate locally with python tools/test-report/generate_report.py after mvnw verify.
